## 小功能规格：本地 CSV 转 Excel 报告

状态：仅规格，尚未实现或进行 Excel 验收。以下为建议的首版范围，不是本次已通过的功能测试。

### 问题与用户故事

面向需要在本地查看月度数据的分析人员，将 CSV 原始记录与汇总结果放入一个 Excel 工作簿，减少手工复制及计算口径不一致。
作为分析人员，我希望保留原始行顺序并获得可核对的总和、均值和逐行增量，以便检查报告。

### 目标

1. 将单个合法 CSV 转为本地 `.xlsx`，原始行数、列名、值及顺序完整保留。
2. 生成汇总表与逐行增量，结果与同一输入的独立 Python 计算一致。
3. 全流程离线运行，所有输出限定在 `/workspace`，不修改输入、不静默覆盖已有文件。

### 非目标

1. 不支持云盘、账号登录、外部分享或自动发送，避免扩大数据访问范围。
2. 不支持多文件合并、数据库接入或定时任务，首版只处理单个本地文件。
3. 不做 OCR、Office 自动化、图表、预测或业务解释，聚焦可核对的数据报告。
4. 不自动填补缺失值、排序、去重或把月份标签推断为具体年份，避免改变原始语义。

### P0 要求与验收条件

- 给定 UTF-8 CSV（允许 BOM），包含 month、value 两列且至少一行有效记录，运行转换后生成含 Data 和 Summary 两个工作表的 `.xlsx`；重新读取工作簿，源字段和行顺序与 CSV 一致，Data 增加 monthly_increase 列。
- 给定本次样本，Summary 总和为 45、均值为 15、行数为 3；Data 增量依次为空白、5、5。给定单行输入，均值等于该值且增量为空白；负数和零作为合法有限数值参与计算。
- 给定重复月份或不连续月份，保留原始记录并明确警告；增量仍表示相邻行之差，不宣称自然月连续，也不自动排序。
- 给定空文件、仅表头、缺列、缺失值、非数值、NaN 或无穷值，返回可定位到字段或数据行的错误，非零退出，不留下最终报告。
- 给定大于 20 MiB 或超过 100,000 行的输入，明确拒绝；给定输出已存在或输出路径解析后不在 `/workspace` 内，拒绝而不覆盖。
- 给定以公式触发字符开头的文本标签，导出为文本而非可执行公式；工作簿不得含宏或外部链接。
- 转换期间不得访问网络、凭据或用户账户，不安装依赖、不修改配置；源 CSV 保持不变。成功时打印输出绝对路径并以退出码 0 结束。
