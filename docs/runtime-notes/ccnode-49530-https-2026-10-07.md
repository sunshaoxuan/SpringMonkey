# 汤猴 49530 端点 HTTPS 升级

## 要求与范围

- 用户于 2026-10-07 授权将汤猴使用的 ccnode 49530 端点改为 HTTPS。
- 当前端点为 `https://ccnode.briconbric.com:49530/v1`。
- 更新模型运行配置、主 agent 缓存、共享环境和启动守护脚本，以及仓库内重建这些入口的默认地址。
- 保留主模型、兜底模型、认证引用、账号、任务调度和 22545 的记忆嵌入配置。
- 配置修改前保存受保护备份，原文件权限和属主保持不变。

## 调查证据

- 主机两份 OpenClaw 配置与两份主 agent 模型缓存仍使用 HTTP。
- 共享环境中的新闻、公共模型、通用兜底与意图兜底地址仍使用 HTTP。
- 启动守护脚本会再次写入 HTTP，需同步迁移以保持重启后的配置。
- HTTPS 证书校验通过；未认证目录请求为 401，使用现有主机认证的目录请求为 200。
- 当前主模型 `gpt-5.3-codex-spark` 的 HTTPS 实际调用为 404，错误类别为 `model_not_found`；现有 Qwen 兜底实际调用为 200 并返回文本。模型选择保持原样，主模型可用性需单独处理。

## 验收

部署后记录迁移幂等性、配置语法、启动守护语法、服务运行态、实际环境及模型调用结果。历史事件文档中的 HTTP 地址保留为当时证据；本次修改只迁移当前执行与重建入口。
